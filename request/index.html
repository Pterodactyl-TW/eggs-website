請求一個 Egg

想在 Pterodactyl-TW 的 Eggs 收藏中看到新的遊戲伺服器、應用程式或語言 Egg 嗎？以下說明如何提出請求。

提出請求前

請先搜尋現有的 Egg 與已開立的 Issue，避免重複請求。你可以直接在本站的 遊戲、應用程式、語言 頁面使用搜尋功能確認是否已經有你需要的 Egg。

請求要提交到哪裡

依照你需要的 Egg 類型，選擇對應的儲存庫提出請求：

🎮

遊戲

適用於所有遊戲伺服器 Egg。

請求遊戲 Egg → 📦

應用程式

適用於非遊戲類的應用程式。

請求應用程式 Egg → 💻

語言

適用於 Python、Node.js 等通用語言 Egg。

請求語言 Egg →

如何撰寫一份好的請求

建立 Egg 請求 Issue 時，請盡量包含以下資訊：

  1. 明確的標題：格式建議為「[Egg 請求]：應用程式名稱」
  2. 說明：描述這個應用程式／遊戲的功能與用途
  3. 官方網站：附上官方網站或 GitHub 儲存庫連結
  4. 安裝文件：附上安裝／設定說明文件的連結
  5. 使用情境：說明為什麼這對社群會有幫助

接下來會發生什麼？

  • 社群維護者會審核你的請求
  • 若請求通過，Issue 會被標記為「Accepted」
  • 維護者或社群成員會著手製作這個 Egg
  • Egg 製作完成後你會收到通知

想參與貢獻嗎？

如果你懂得如何製作 Egg，歡迎直接透過 Pull Request 貢獻！可以到 Pterodactyl-TW GitHub 開始參與。 若你想加入我們的繁體中文化服務團隊，一起維護 Eggs、Panel、Wings 與文件的翻譯，也歡迎透過 Discord 與我們聯絡。

本站由 Pterodactyl-TW 繁體中文化服務團隊 維護，資料即時取自 game-eggs、 application-eggs、 generic-eggs 三個倉庫，若有翻譯問題歡迎透過 Discord 與我們聯繫。
