Request an Egg

找不到你想要的 Egg，或發現某個 Egg 的翻譯有問題？以下是提出請求的管道。

新增 / 更新 Egg

我們的 Egg 皆同步自 Pterodactyl 官方 Egg 儲存庫並進行繁體中文化，若你想請求新增或更新一個 Egg：

  • 若官方 game-eggs / application-eggs 已有該 Egg，我們會在同步時一併翻譯，可以直接到我們對應的儲存庫開 Issue 提醒我們優先處理：
    • 在 game-eggs 開 Issue
    • 在 application-eggs 開 Issue
    • 在 generic-eggs 開 Issue
  • 若官方尚未收錄該遊戲／應用程式，請先至官方倉庫依照他們的貢獻指南提交 Egg，待官方收錄後我們會同步翻譯。
  • 若是翻譯內容本身有錯誤或需要更新，歡迎直接開 Pull Request，或透過 Discord 告訴我們。

加入我們

如果你想加入繁體中文化服務團隊，一起維護 Eggs、Panel、Wings 與文件的翻譯，歡迎透過 Discord 與我們聯絡。

本站由 Pterodactyl-TW 繁體中文化服務團隊 維護，資料即時取自 game-eggs、 application-eggs、 generic-eggs 三個倉庫，若有翻譯問題歡迎透過 Discord 與我們聯繫。
